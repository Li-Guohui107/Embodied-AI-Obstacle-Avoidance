# 06 · 实验与指标分析

## 1. 运行实验

```bash
python -m embodied_nav.main --seed 7
```

程序会打印：

- 任务是否成功；
- 执行步数；
- 实际路径长度；
- 搜索扩展节点总数；
- 重新规划次数。

## 2. 指标解释

**路径长度**：机器人实际执行的相邻格子步数总和。当前每次移动代价为 1，因此路径长度等于执行步数。

**扩展节点数**：A* 搜索过程中从优先队列取出并展开的节点数量。它可粗略反映搜索工作量，但不等同于运行时间。

**重新规划次数**：动态环境变化导致重新调用规划器的次数。

## 3. 建议实验

| 实验 | 修改内容 | 观察重点 |
