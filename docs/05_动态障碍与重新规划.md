# 05 · 动态障碍与重新规划

## 1. 为什么需要闭环？

静态路径规划假设地图不变。但现实环境中，行人、车辆或其他物体可能移动，原本可行的路径可能突然被阻断。

因此机器人不能只规划一次，而应在执行过程中持续检查环境。

## 2. 本项目如何模拟？

仿真运行到指定步数时，在地图中添加一个新障碍物。机器人检查剩余路径：

- 如果剩余路径仍然可通行，就继续执行；
- 如果路径被阻断，就从当前位置重新调用 A*；
- 如果不存在新路径，就报告任务失败。

## 3. 闭环逻辑

\[
\text{规划}\rightarrow\text{执行}\rightarrow\text{观察变化}
\rightarrow
\begin{cases}
\text{继续执行}, & \text{路径安全}\\
\text{重新规划}, & \text{路径受阻}
\end{cases}
\]

## 4. 重要说明

当前动态障碍是预先安排的事件，不是由摄像头或激光雷达实时检测得到。它用于教学演示“地图更新后重新规划”的机制。
