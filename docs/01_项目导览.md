# 01 · 项目导览：让机器人在二维世界中自主导航

## 1. 学习目标

完成本项目后，你应该能够解释并实现一个最小导航闭环：

**环境表示 → 获取地图信息 → 路径规划 → 运动执行 → 反馈检查 → 必要时重新规划。**

这条链路与具身智能的核心思想有关：智能体通过感知环境、采取行动并接收反馈，在环境中完成任务。

## 2. 任务定义

给定：

- 一张二维栅格地图；
- 机器人起点 `start`；
- 目标位置 `goal`；
- 一组不可通行的障碍物。

要求机器人从起点移动到目标点，不能穿过障碍物。

## 3. 模块分工

| 文件 | 职责 |
|---|---|
| `environment.py` | 管理地图和障碍物 |
| `planner.py` | 搜索一条可行路径 |
| `controller.py` | 沿路径执行一步 |
| `simulation.py` | 组织规划、执行和重规划 |
| `visualization.py` | 生成俯视图和动画 |
| `visualization_3d.py` | 把同一结果画成三维场景 |
| `main.py` | 配置场景并启动实验 |

## 4. 为什么从二维栅格开始？

真实机器人涉及连续空间、传感器噪声、动力学约束和复杂碰撞检测。栅格地图把连续环境离散化，让初学者先理解路径搜索与反馈机制。

每个格子只有两种状态：

- `0`：可通行；
- `1`：障碍物。

后续可以把栅格占据状态替换为激光雷达或深度相机建立的地图。
