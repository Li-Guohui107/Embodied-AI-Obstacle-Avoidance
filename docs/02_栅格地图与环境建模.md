# 02 · 栅格地图与环境建模

## 1. 二维栅格地图

将环境划分为 `rows × cols` 个格子。项目使用 NumPy 数组保存占据状态：

```python
self.occupancy = np.zeros((rows, cols), dtype=np.uint8)
```

数组元素为 0 表示空闲，为 1 表示障碍。

## 2. 坐标约定

本项目统一使用 `(row, col)`，也就是 `(行, 列)`：

- `row` 沿竖直方向变化；
- `col` 沿水平方向变化；
- 左上角格子是 `(0, 0)`。

注意：Matplotlib 绘图时，横轴对应 `col`，纵轴对应 `row`。这是初学者容易混淆的地方。

## 3. 邻接关系

当前采用四邻接模型：

\[
N(r,c)=\{(r-1,c),(r+1,c),(r,c-1),(r,c+1)\}
\]

只有在地图范围内且没有障碍的邻居才允许进入。

## 4. 动手实验

打开 `examples/custom_scene.py`，尝试：

1. 修改 `rows` 和 `cols`；
2. 在不同位置添加障碍物；
3. 把障碍墙的缺口改到其他行；
4. 观察是否仍能找到路径。

思考：如果把起点或终点放在障碍物上，为什么程序应该报错，而不是继续搜索？
