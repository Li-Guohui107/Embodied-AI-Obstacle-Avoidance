# 03 · A* 路径规划算法

## 1. A* 的核心思想

A* 是一种启发式图搜索算法。它综合考虑：

- 已经走过的代价；
- 从当前位置到目标点的估计代价。

评价函数：

\[
f(n)=g(n)+h(n)
\]

其中：

- \(g(n)\)：起点到节点 \(n\) 的实际代价；
- \(h(n)\)：节点 \(n\) 到目标的启发式估计；
- \(f(n)\)：经过节点 \(n\) 的总代价估计。

## 2. 曼哈顿距离

因为机器人只允许上下左右移动，所以使用：

\[
h(n)=|r_n-r_g|+|c_n-c_g|
\]

在每步代价为 1 的四邻接栅格中，曼哈顿距离不会高估实际最短距离，因此是可采纳启发式。

## 3. 搜索流程

1. 将起点放入优先队列；
2. 取出 `f` 值最小的节点；
3. 如果该节点是目标，回溯路径；
4. 否则检查所有可通行邻居；
5. 如果找到更低的累计代价，更新父节点和代价；
6. 重复直到找到目标或队列为空。

## 4. 为什么需要父节点？

搜索时保存 `came_from[neighbor] = current`。到达目标后，从目标沿父节点反向回溯，就能恢复完整路径。

## 5. 复杂度直觉

A* 的实际搜索规模与地图结构、障碍分布和启发式质量有关。最坏情况下仍可能扩展大量节点；好的启发式通常能显著减少无效搜索。

## 6. 练习

- 把曼哈顿距离改成欧氏距离，思考在四邻接模型下它是否仍然可采纳。
- 实现 Dijkstra（令 `h(n)=0`），比较扩展节点数。
- 将四邻接改成八邻接时，重新设计移动代价和启发式函数。
