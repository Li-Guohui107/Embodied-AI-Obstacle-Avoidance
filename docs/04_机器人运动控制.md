# 04 · 机器人运动控制

## 1. 规划不等于执行

规划器给出的是一串离散位置，例如：

```python
[(1, 1), (1, 2), (1, 3), (2, 3)]
```

控制器负责把路径转换成每个仿真步的动作。本项目采用最简单的离散控制：每一步移动到路径上的下一个格子。

## 2. 当前控制模型

机器人状态仅包含当前位置：

\[
s_t=(r_t,c_t)
\]

动作是四个方向之一：

\[
a_t \in \{\text{上},\text{下},\text{左},\text{右}\}
\]

状态更新由环境规则决定：

\[
s_{t+1}=T(s_t,a_t)
\]

如果下一格是障碍物，动作不能执行。

## 3. 真实机器人中的差异

真实移动机器人通常使用连续状态，例如：

\[
x=(p_x,p_y,\theta,v,\omega)
\]

其中位置、朝向、线速度和角速度都可能需要控制。实际系统还要考虑轮胎打滑、加速度限制、定位误差和控制频率。
